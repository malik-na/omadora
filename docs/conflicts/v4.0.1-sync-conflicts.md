# Conflict audit: omarchy-mac v4.0.1 → omarchy-mac-fedora

Repo: omarchy-mac-fedora. Target branch: `sync/omarchy-mac-v4.0.1` (from `main` @ `1ebe1307`).
Upstream source: https://github.com/omarchy-mac/omarchy-mac tag `v4.0.1` (`5f3abc36`).
Merge-base: `8147489f` (shared quattro ancestor; Fedora's prior sync was from basecamp/omarchy).

Strategy: single `git merge --no-ff v4.0.1`. Divergence at merge start: ~410 ours / ~1020 theirs.
Conflict surface: **122** paths (78 UU, 31 DU, 13 UD).

Fork invariants that win every conflict: **dnf not pacman; aarch64 / Apple Silicon only;
dracut not mkinitcpio/limine; firewalld; NetworkManager + wpa_supplicant; wf-recorder fallback;
git-clone delivery; Fedora 44+ Asahi Minimal.**

Validated on metal (Fedora Asahi Remix 44, aarch64): `macsmc-battery` (cycle_count=694),
backlight `apple-panel-bl`, `select_recorder_backend` → `wf-recorder`, audio packages resolve as
`pipewire-pulseaudio` (not Arch `pipewire-pulse`), `powerprofilesctl` placeholder profiles soft-exit.
