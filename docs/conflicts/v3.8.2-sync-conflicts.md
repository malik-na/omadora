# Conflict audit: upstream sync v3.5.0 -> v3.8.2

Repo: omarchy-mac-fedora. Target branch: `sync/upstream-v3.8.2` (branched from `dev`).
Upstream source: https://github.com/basecamp/omarchy, tags fetched under `upstream/*`.
Base of the sync: `upstream/v3.5.0` = 76d09b29 (already an ancestor of `dev` - true 3-way base).

Strategy: one `git merge --no-ff` per upstream tag (never rebase, never squash), so every merge commit
carries both parents and its conflict resolution is legible in history. Fork-side invariants that win
every conflict: dnf not pacman; aarch64 only (skip Intel/NVIDIA/Framework/ASUS/Surface/Dell/T2/Lenovo
x86 hardware); alacritty not ghostty; dracut not mkinitcpio/limine.

Each tag section lists the merge SHA, both parents, and one line per conflicted file on how it was
resolved and why.
